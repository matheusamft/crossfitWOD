# CrossFit WOD Tracker

## Descrição

Uma aplicação simples onde é possível cadastrar WODs de CrossFit, contendo nome, tipo, descrição e tempo. Cada WOD também possui seus respectivos exercícios, informando o exercício, o número de repetições e a carga sugerida.

Além disso, é possível cadastrar o resultado realizado em cada WOD e adicionar uma observação, permitindo acompanhar a evolução ao longo do tempo.
